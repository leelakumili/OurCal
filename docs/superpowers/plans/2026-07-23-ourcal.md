# OurCal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local macOS Python app that unifies all calendars from the author's 5 Google accounts into one auto-polling dashboard and creates events/busy-blocks across any selection of them (Copies or Invite mode, per-account blocking/non-blocking).

**Architecture:** One deliverable file `ourcal.py` with the HTML page embedded as a string. Internally layered CONFIG → BOOTSTRAP → GOOGLE → NORMALIZE → MERGE → DEMO → SERVICE → HTTP → HTML. Google client imports are **lazy** (inside GOOGLE functions); bootstrap and server-start run **only inside `main()`** under `if __name__ == "__main__"`. So `import ourcal` is side-effect-free and every pure function is unit-testable with stdlib `unittest`, no OAuth. A `OURCAL_DEMO=1` path swaps the Google backend for an in-memory fixture store so the whole UI/API is exercisable offline.

**Tech Stack:** Python 3.9+ stdlib (`http.server`, `json`, `datetime`, `zoneinfo`, `urllib`, `venv`, `subprocess`), `google-api-python-client` + `google-auth-oauthlib` (installed at first run into `.ourcal-venv`). Tests: stdlib `unittest`. Frontend: one self-contained HTML string (inline CSS/JS, no CDN/framework).

## Global Constraints

Every task's requirements implicitly include these (verbatim from the spec):

- **Python 3.9+ only.** No Node/Electron/CDN/framework. UI is a local web app.
- Server: stdlib `ThreadingHTTPServer` bound to **`127.0.0.1:8756`** (`PORT`).
- Single deliverable file **`ourcal.py`** with the HTML embedded as a string.
- Google Calendar via `google-api-python-client` + `google-auth-oauthlib`; OAuth `InstalledAppFlow`; Desktop credential in `credentials.json` next to the app; one `token_<slug>.json` per account; auto-refresh of expired tokens.
- First-run bootstrap: on `ImportError`, create `.ourcal-venv` next to the app, pip-install deps, `os.execve` re-launch; guard infinite re-exec with env var `OURCAL_REEXEC`.
- Name everything **"OurCal"** (UI title, consent-screen app name, launcher).
- Config block at top of `ourcal.py`: `ACCOUNTS = [{label,email}]`, `TIMEZONE = "America/Los_Angeles"`, `DAYS_AHEAD = 30`, `POLL_MINUTES = 5`, `PORT = 8756`.
- Calendar filter: include a calendar iff `selected` or `primary`; skip any id containing `#holiday`, `#contacts`, or `addressbook`.
- `events.list` with `singleEvents=True`, `orderBy="startTime"`, window now → +`DAYS_AHEAD` days.
- All-day event body uses **exclusive** end date (`{"date": start + 1 day}`). Timed uses `{"dateTime":"YYYY-MM-DDTHH:MM:00","timeZone":TIMEZONE}`.
- Empty title defaults to **"Busy"**. `busy = transparency != "transparent"`.
- Dedupe by `(iCalUID, start)`; merge labels into badges; **never mutate source dicts**.
- Colorblind-safe palette (light): `#2a78d6 #eb6834 #1baf7a #eda100 #e87ba4`; dark-adjusted steps. System font stack, no external fonts.
- `ACCOUNTS` ships as (labels confirmed by requester):

# ── NORMALIZE ───────────────────────────────────────────────────────────
def normalize(raw, label, calendar_name):
    """Google event dict → normalized event (spec §6). Pure; reads inputs only."""
    start_obj = raw.get("start", {}) or {}
    end_obj = raw.get("end", {}) or {}
    all_day = "date" in start_obj
    start = start_obj.get("date") if all_day else start_obj.get("dateTime")
    end = end_obj.get("date") if all_day else end_obj.get("dateTime")
    return {
        "uid": raw.get("iCalUID", ""),
        "title": (raw.get("summary") or "").strip() or "Busy",
        "start": start,
        "end": end,
        "allDay": all_day,
        "busy": raw.get("transparency", "opaque") != "transparent",
        "location": raw.get("location") or None,
        "join": raw.get("hangoutLink") or None,
        "labels": [label],
        "calendars": [calendar_name],
        "guests": len(raw.get("attendees", []) or []),
    }
```

# ── MERGE ───────────────────────────────────────────────────────────────
def _extend_unique(dst, src):
    for x in src:
        if x not in dst:
            dst.append(x)


def merge_events(events):
    """Dedupe by (uid, start), badge-merge. Copy-on-write; never mutates inputs."""
    merged = {}
    order = []
    passthrough = []  # events with empty uid never merge
    for ev in events:
        uid = ev.get("uid") or ""
        if not uid:
            passthrough.append(dict(ev))
            continue
        key = (uid, ev.get("start"))
        if key not in merged:
            merged[key] = {**ev, "labels": list(ev["labels"]),
                           "calendars": list(ev["calendars"])}
            order.append(key)
        else:
            m = merged[key]
            _extend_unique(m["labels"], ev["labels"])
            _extend_unique(m["calendars"], ev["calendars"])
            m["busy"] = m["busy"] or ev["busy"]
            m["guests"] = max(m["guests"], ev["guests"])
            m["join"] = m["join"] or ev["join"]
            m["location"] = m["location"] or ev["location"]
    out = [merged[k] for k in order] + passthrough
    out.sort(key=lambda e: e["start"] or "")
    return out
```

# ── EVENT BODY ──────────────────────────────────────────────────────────
def build_event_body(payload, blocking):
    """Create-payload → Google events.insert body (spec §8)."""
    title = (payload.get("title") or "").strip() or "Busy"
    body = {
        "summary": title,
        "transparency": "opaque" if blocking else "transparent",
    }
    date = payload["date"]
    if payload.get("allDay"):
        start_d = datetime.strptime(date, "%Y-%m-%d").date()
        end_d = start_d + timedelta(days=1)  # Google end date is exclusive
        body["start"] = {"date": start_d.isoformat()}
        body["end"] = {"date": end_d.isoformat()}
    else:
        body["start"] = {"dateTime": f"{date}T{payload['startTime']}:00",
                         "timeZone": TIMEZONE}
        body["end"] = {"dateTime": f"{date}T{payload['endTime']}:00",
                       "timeZone": TIMEZONE}
    if payload.get("location"):
        body["location"] = payload["location"]
    if payload.get("notes"):
        body["description"] = payload["notes"]
    return body
```

# ── GOOGLE ──────────────────────────────────────────────────────────────
SCOPES = ["https://www.googleapis.com/auth/calendar"]
_SKIP_SUBSTR = ("#holiday", "#contacts", "addressbook")
APP_DIR = os.path.dirname(os.path.abspath(__file__))


def should_include_calendar(item):
    cid = item.get("id", "")
    if any(s in cid for s in _SKIP_SUBSTR):
        return False
    return bool(item.get("selected") or item.get("primary"))


def token_path(label):
    return os.path.join(APP_DIR, f"token_{slug(label)}.json")


def creds_for(label):
    """Load/refresh creds for an account; run InstalledAppFlow if absent."""
    from google.oauth2.credentials import Credentials
    from google.auth.transport.requests import Request
    from google_auth_oauthlib.flow import InstalledAppFlow
    path = token_path(label)
    creds = None
    if os.path.exists(path):
        creds = Credentials.from_authorized_user_file(path, SCOPES)
    if creds and creds.valid:
        return creds
    if creds and creds.expired and creds.refresh_token:
        creds.refresh(Request())
    else:
        cred_file = os.path.join(APP_DIR, "credentials.json")
        flow = InstalledAppFlow.from_client_secrets_file(cred_file, SCOPES)
        creds = flow.run_local_server(port=0)
    with open(path, "w") as f:
        f.write(creds.to_json())
    return creds


def service_for(label):
    from googleapiclient.discovery import build
    return build("calendar", "v3", credentials=creds_for(label),
                 cache_discovery=False)


def list_account_events(label, email, time_min, time_max):
    """Return (normalized_events, error_or_None) for one account."""
    try:
        svc = service_for(label)
        events = []
        page_token = None
        cals = []
        while True:
            resp = svc.calendarList().list(pageToken=page_token).execute()
            cals.extend(resp.get("items", []))
            page_token = resp.get("nextPageToken")
            if not page_token:
                break
        for cal in cals:
            if not should_include_calendar(cal):
                continue
            cal_name = cal.get("summaryOverride") or cal.get("summary") or cal["id"]
            page = None
            while True:
                resp = svc.events().list(
                    calendarId=cal["id"], singleEvents=True, orderBy="startTime",
                    timeMin=time_min, timeMax=time_max, pageToken=page,
                    maxResults=2500).execute()
                for raw in resp.get("items", []):
                    events.append(normalize(raw, label, cal_name))
                page = resp.get("nextPageToken")
                if not page:
                    break
        return events, None
    except Exception as e:  # per-account isolation
        return [], f"{label}: {type(e).__name__} — re-auth or check access"


def _rfc3339(dt):
    return dt.replace(microsecond=0).isoformat()


def _google_collect(now):
    from datetime import timedelta
    time_min = _rfc3339(now)
    time_max = _rfc3339(now + timedelta(days=DAYS_AHEAD))
    all_events, errors = [], []
    for a in ACCOUNTS:
        evs, err = list_account_events(a["label"], a["email"], time_min, time_max)
        all_events.extend(evs)
        if err:
            errors.append({"label": a["label"], "message": err})
    return merge_events(all_events), errors


def _email_for(label):
    for a in ACCOUNTS:
        if a["label"] == label:
            return a["email"]
    return None


def _google_create(payload):
    mode = payload.get("mode", "copies")
    targets = payload["targets"]
    results = []
    if mode == "invite":
        host = payload["inviteFrom"]
        attendees = [{"email": _email_for(t["label"])}
                     for t in targets if t["label"] != host]
        host_blocking = next((t["blocking"] for t in targets
                              if t["label"] == host), True)
        body = build_event_body(payload, host_blocking)
        if attendees:
            body["attendees"] = attendees
        try:
            svc = service_for(host)
            ev = svc.events().insert(calendarId="primary", body=body,
                                     sendUpdates="all").execute()
            results.append({"label": host, "ok": True,
                            "htmlLink": ev.get("htmlLink")})
        except Exception as e:
            results.append({"label": host, "ok": False, "error": str(e)})
    else:  # copies
        for t in targets:
            body = build_event_body(payload, t["blocking"])
            try:
                svc = service_for(t["label"])
                ev = svc.events().insert(calendarId="primary", body=body,
                                         sendUpdates="none").execute()
                results.append({"label": t["label"], "ok": True,
                                "htmlLink": ev.get("htmlLink")})
            except Exception as e:
                results.append({"label": t["label"], "ok": False,
                                "error": str(e)})
    return {"ok": all(r["ok"] for r in results), "results": results}

# ── HTTP ────────────────────────────────────────────────────────────────
class OurCalHandler(BaseHTTPRequestHandler):
    def log_message(self, *args):
        pass  # quiet

    def _send(self, code, body, ctype="application/json"):
        data = body.encode() if isinstance(body, str) else body
        self.send_response(code)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

    def do_GET(self):
        try:
            if self.path == "/" or self.path.startswith("/?"):
                html = PAGE.replace("__POLL_MS__", str(POLL_MINUTES * 60000))
                self._send(200, html, "text/html; charset=utf-8")
            elif self.path == "/api/events":
                self._send(200, json.dumps(get_events()))
            else:
                self._send(404, json.dumps({"error": "not found"}))
        except Exception as e:
            self._send(500, json.dumps({"error": str(e)}))

    def do_POST(self):
        try:
            if self.path != "/api/create":
                self._send(404, json.dumps({"error": "not found"}))
                return
            length = int(self.headers.get("Content-Length", 0))
            payload = json.loads(self.rfile.read(length) or b"{}")
            self._send(200, json.dumps(create_event(payload)))
        except Exception as e:
            self._send(500, json.dumps({"error": str(e)}))


def make_server(port):
    return ThreadingHTTPServer(("127.0.0.1", port), OurCalHandler)


def run_server():
    try:
        server = make_server(PORT)
    except OSError as e:
        print(f"OurCal: cannot bind 127.0.0.1:{PORT} ({e}). "
              f"Something may already use it — change PORT at the top of "
              f"ourcal.py or free the port (lsof -ti tcp:{PORT}).")
        raise SystemExit(1)
    url = f"http://127.0.0.1:{PORT}"
    print(f"OurCal running at {url}  (Ctrl-C to stop)")
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        server.shutdown()
```

# ── BOOTSTRAP ───────────────────────────────────────────────────────────
DEPS = ["google-api-python-client", "google-auth-oauthlib"]
VENV_DIR = os.path.join(APP_DIR, ".ourcal-venv")


def _google_importable():
    try:
        import googleapiclient  # noqa: F401
        import google_auth_oauthlib  # noqa: F401
        return True
    except ImportError:
        return False


def needs_bootstrap():
    if is_demo() or os.environ.get("OURCAL_REEXEC") == "1":
        return False
    return not _google_importable()


def ensure_deps():
    if not needs_bootstrap():
        return
    import subprocess, sys, venv
    print("OurCal: first-run setup — creating .ourcal-venv and installing deps…")
    venv.EnvBuilder(with_pip=True).create(VENV_DIR)
    py = os.path.join(VENV_DIR, "bin", "python")
    subprocess.check_call([py, "-m", "pip", "install", "-q", "--upgrade", "pip"])
    subprocess.check_call([py, "-m", "pip", "install", "-q", *DEPS])
    env = dict(os.environ, OURCAL_REEXEC="1")
    os.execve(py, [py, os.path.abspath(__file__)], env)


def main():
    if not is_demo():
        ensure_deps()
    run_server()
